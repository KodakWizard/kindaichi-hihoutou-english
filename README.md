**[Download 1.0](https://github.com/KodakWizard/kindaichi-hihoutou-english/releases/download/v1.0/Kindaichi_Hihoutou_English_v1.0-Patch.zip)** · [How to install](PATCHING_GUIDE.md) · [Share feedback](https://github.com/KodakWizard/kindaichi-hihoutou-english/issues)

I've been working on an English translation of *Kindaichi Shounen no Jikenbo — Hihou-tou Arata naru Sangeki* so more people can enjoy this PlayStation detective game.

The story and dialogue choices are translated, along with the maps, case notes, evidence documents and save/load screens. I've tried to keep the clues clear and make the English graphics feel at home in the game.

**Version 1.0 is here**, now with reviewed English movie subtitles. Enjoy the mystery, and let me know how you get on.

## What's translated?

| Part of the game | Progress |
| --- | --- |
| Story dialogue | **100%** of identified passages — 6,858 in English |
| Dialogue choices | **100%** of identified choices — 790 in English |
| Maps and character introductions | Translated |
| Case notes | All three days translated and revised |
| Evidence documents | Licence, marriage forms, Written Pledge and timetable translated |
| Torii verses | English added alongside the original Japanese and cipher symbols |
| Save and load screens | English labels with matching lettering |
| Movie speech | 237 reviewed English subtitle cues across 14 movies; Japanese voices retained |

The percentages refer to the dialogue and choices found in the script audit. Playthrough testing is still in progress.

## Getting started

You'll need your own copy of the Japanese game, **SLPS-00601**, in BIN/CUE format.

1. Download the [1.0 patch ZIP](https://github.com/KodakWizard/kindaichi-hihoutou-english/releases/download/v1.0/Kindaichi_Hihoutou_English_v1.0-Patch.zip) and extract it.
2. Apply the BPS patch to your original BIN using [Floating IPS](https://github.com/Sir-Walrus/Flips/releases).
3. Keep the patched BIN beside the included CUE, then open the CUE to play.

The ZIP includes step-by-step instructions and the matching CUE. See the [installation guide](PATCHING_GUIDE.md) if you need a hand.

## Help make it better

Feedback from people playing the game helps me keep improving the translation. Please let me know if you find:

- A line that sounds awkward or is hard to follow.
- Text that gets cut off, or a graphic that's difficult to read.
- A choice or clue that doesn't seem to work as it should.
- A crash, hang or anything that stops you progressing.

[Open an issue here](https://github.com/KodakWizard/kindaichi-hihoutou-english/issues). A screenshot and a quick note about where you were in the game would be really helpful. Please mention **1.0** so I know which version you're using.

If you reach an ending, I'd love to hear that too!

## A note on the original artwork

The title artwork, credits and writing within movies are kept original. Movie speech has English subtitles.

The current build has passed manual gameplay checks and file verification. Feedback on complete routes, endings and original PlayStation hardware is still welcome.
