# Reviewed movie subtitles

These 14 English SRTs supply the 237 cues used in 1.0. They replace the earlier subtitle drafts.

Times refer to native sector-aligned review movies, with the one-hour editing timeline offset removed. Review exports include one initial padding frame. When burning into original STR source frames, map each start/end as `ceil(seconds * 15000 / 1001) - 1`, clamping to the original source-frame range. Keep normal movie speed. Bold styling is supplied by the game patch.

Original movie/audio files are not included. DAI2B and LOGO have no supplied subtitle cues. These SRTs are English translation data, separate from the MIT-licensed software tools.
