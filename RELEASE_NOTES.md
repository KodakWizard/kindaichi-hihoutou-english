# Kindaichi English v0.1.0-alpha

The first public English alpha for the Japanese PlayStation release, SLPS-00601.

## Downloads

- `Kindaichi_Hihoutou_English_v0.1.0-alpha.bps` is the game patch. Apply it to the original Japanese **BIN** with a BPS patcher. Keep the patched BIN and a matching CUE together.
- `Kindaichi-English-Editor-v0.1.0-alpha.zip` is the Windows x64 translation editor. Extract the entire folder and open `KindaichiTranslationEditor.exe`. All 6,852 English dialogue entries and 778 choices are preloaded. You can browse scenes, save drafts and export edits. Game rebuilding uses the separate development workbench.

The supported input is a single-track MODE2/2352 BIN with SHA-1 `65f582ffe78b5fa55e45d0c163ba2e67a5b15e15`. The translated output SHA-256 is `162b6dd0a105ecfbe4d75f2f5c1da8bac1a0521a25291b35f915c4f8506be4b8`.

The alpha includes translated dialogue, choices, selected graphics, and revised save and load typography. Further testing across story routes and on original hardware is welcome.
